## About Me

I'm a second-year **Computer Engineering** student at K J Somaiya School of Engineering, with double minors in **Software & Mobile Application Development** and **FinTech**. I like turning ideas into things I can test: a robot finding its way, a game explaining a money decision, or a model working with language. I'm equally curious about how teams and products work, so I'm exploring **tech, management and marketing**.

Beyond code, I've worked in startup incubation at **riidl** and event marketing at **CodeCell**. Debating, traveling and reading are also a part of my life.

## Current Projects

- **Robocon** — Computer vision navigation using three cameras, custom YOLO11 models and grid-based path planning.
- **HowToLife** — A 3D browser game set in Mumbai that explores financial literacy, budgeting and career choices.
- **Floatchatlite** — Making raw ocean argo data directly accessible using a Natural Language Processing interface.
